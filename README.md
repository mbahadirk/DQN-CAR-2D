<h2> Vehicle Simulation Environment & DQN Q-Learning </h2>

This project provides a 2D vehicle simulation environment developed using Pygame. The goal is to train the vehicle to reach a designated target using deep reinforcement learning (DQN and Q-Learning) algorithms.

<h2>Project Status </h2>

Significant progress has been made, but the desired results have not yet been achieved. Although the simulation environment is functional, reinforcement learning models require further improvements in performance.

The code structure is somewhat complex in certain areas, but it offers a usable framework for developers.

<h2>Usage </h2>

To run the project:
<ul>
<li>Install the required dependencies with <code>pip install -r requirements.txt</code> </li>

<li>Start the simulation environment with starting <code>Simulation.py</code> </li>

<li>Train your model using DQN or Q-Learning algorithms. <code>DQN/train.py</code> or <code>Q-Learning/train.py</code> </li>

</ul>
